# Wild Bird — Figma 웹 프로토타입 v3

## 실행

1. ZIP을 풀고 `wild-bird` 폴더 전체를 보관합니다.
2. Mac에서 `시작.command`를 더블클릭합니다.
3. 브라우저가 열리면 사진과 꿈을 입력합니다. 입력란 밖의 종이 또는 `I want to be a ...`를 누르면 펼쳐집니다. Enter로도 진행할 수 있습니다.
4. 실행 중에는 터미널 창을 열어 두세요. 종료는 Control+C입니다.

Python 3이 필요하며 이 컴퓨터에는 설치되어 있습니다. 다른 환경에서는 이 폴더에서 `python3 server.py`를 실행하세요. `index.html`을 직접 열면 번역과 얼굴 탐지가 정상 작동하지 않으므로 실행 파일을 사용해 주세요.

## 반영된 기능

- 최신 Figma의 데스크톱·모바일 시작 화면과 우주비행사 / 박사 / 가수 완성 예시
- 원본의 검은 테두리를 포함한 하늘 배경이 전체 화면을 채움. 바인더와 사진은 비율 유지
- 입력한 첫 페이지가 함께 넘어가는 약 3초의 연속 넘김, 종이 곡률·그림자·링 앞뒤 가림
- 사진은 잘라내거나 늘리지 않고 전체가 들어가도록 배치
- 한국어 단어·문구를 영어로 번역. 직업 사전의 항목으로 제한하지 않음
- `I want to be a ...` 유지, `Wild {번역}.`와 한국어 문구 변경
- 마지막 한글 음절의 받침에 따라 ‘이/가’ 선택
- 완성 화면의 모든 그림 스티커(건물 포함)를 클릭하여 이동·크기·회전 조절
- 이미지 저장: 현재 화면 전체를 PNG로 다운로드. 하단 세 버튼, 선택 테두리, 안내문 제외
- 공유하기: 호버·눌림 효과만 적용
- 처음으로 돌아가기: 사진·입력·조정을 비우고 시작 화면으로 돌아감

영문이나 숫자로 끝나는 입력의 한국어 조사는 기본 ‘가’를 사용합니다. 일반적인 한글 입력은 자동 판별됩니다.

## 스티커 조작

스티커를 누르면 파란 바운딩 박스가 나타납니다.

- 내부 드래그: 이동
- 모서리·변 손잡이 드래그: 원래 비율을 유지하며 크기 조절
- 바깥 원형 손잡이 드래그: 회전 (Shift를 누르면 15도 단위)
- 방향키: 미세 이동, Shift+방향키: 크게 이동
- 빈 공간 클릭 또는 Escape: 선택 해제

얼굴은 기기 안에서 탐지합니다. 여러 얼굴이면 가장 큰 얼굴을 기준으로 헬멧·학사모·넥타이·마이크 등 해당 테마의 스티커를 맞춥니다. 나머지 장식은 Figma 배치를 따릅니다. 탐지가 어려운 사진은 기본 위치에서 직접 조정할 수 있습니다.

음악·가수 관련 입력은 가수, 의사·박사 관련 입력은 박사 예시를 사용하고, 그 외 입력은 우주 테마를 사용합니다. 이는 장식 선택 기준일 뿐 번역할 수 있는 단어를 제한하지 않습니다. 실제 AI 이미지 생성은 사용하지 않습니다.

## 번역과 사진 처리

번역에는 인터넷 연결이 필요합니다. 입력한 꿈 텍스트만 [MyMemory 번역 API](https://mymemory.translated.net/doc/spec.php)로 전송됩니다. 무료 서비스의 사용량 제한이나 연결 오류가 있으면 재시도 안내를 표시합니다. 자동 번역 특성상 문맥에 따른 결과 차이는 있을 수 있습니다.

사진과 얼굴 좌표는 외부로 보내지 않습니다. 동봉된 MediaPipe 모델이 브라우저 안에서 처리합니다. 결과는 새로고침 또는 처음으로 돌아가기를 누르면 초기화됩니다. 데스크톱·모바일 배치를 오갈 때 각 배치의 스티커 조정은 따로 유지됩니다.

## 디자인과 파일

원본 Figma 페이지 `263:498`의 최신 프레임을 기준으로 레이어를 분리했습니다. `layouts.js`는 각 요소의 위치·크기·회전·크롭 정보를 보관합니다. `app.js`는 화면 합성, 넘김, 얼굴 탐지, 스티커 편집과 저장을 담당하고, `server.py`는 로컬 실행과 번역 연결을 담당합니다.

폰트는 컴퓨터에 설치된 Aquiline DEMO와 Pretendard Regular/Medium/SemiBold를 사용했습니다. 추가 폰트 파일은 필요하지 않습니다. 정식 Aquiline 웹폰트를 준비하면 `assets/fonts/Aquiline.otf`를 교체할 수 있습니다.

종이와 링은 원본 이미지 기반 깊이 합성으로 연출합니다. 정밀한 금속·종이 물리 시뮬레이션은 아니며, 종이 폭과 구멍은 애니메이션에 맞춰 통일했습니다. 운영체제에서 ‘동작 줄이기’를 켜면 넘김을 생략합니다.

## 확인한 항목

- 1440×810 데스크톱, 390×762 모바일 시작·완성 배치
- 세 가지 Figma 예시, 첫 페이지와 중간 넘김 장면
- “행복한 사람” → “Happy people” 자유 문구 번역
- 실제 사진 업로드 및 로컬 얼굴 탐지
- 스티커 선택, 비율 유지 크기 조절, 회전
- PNG 다운로드 및 버튼·선택 테두리 제외
- 공유 버튼의 눌림 효과, 처음으로 돌아가기
- 한글 받침과 세로·정사각형·가로·파노라마 비율 계산

검토용 주소: 실행된 주소 뒤에 `?example=astronaut`, `?example=doctor`, `?example=singer`를 붙이면 예시를 바로 볼 수 있습니다. `?frame=1500`은 모션 1.5초 지점입니다.
